# Claude Code 12 Rules

프로젝트의 `CLAUDE.md`에 바로 넣어 쓸 수 있는 12개 작업 규칙입니다.

Andrej Karpathy의 Claude Code 4원칙을 출발점으로 삼아, 실제 프로젝트에서 자주 빠지는 판단 범위, 토큰 예산, 충돌 처리, 테스트, 체크포인트, 실패 보고 규칙을 더했습니다.

## 무엇이 들어 있나요

| 구분 | 규칙 |
|---|---|
| 출발 원칙 | Think Before Coding, Simplicity First, Surgical Changes, Goal-Driven Execution |
| 보강 규칙 | 판단과 결정적 작업 분리, 토큰 예산, 충돌 처리, 사전 읽기, 테스트 의도, 체크포인트, 기존 관례, 누락 없는 실패 보고 |

## 적용 방법

1. 이 저장소의 `CLAUDE.md`를 사용할 프로젝트 루트에 복사합니다.
2. 기존 프로젝트 규칙이 있으면 충돌하는 문장만 남기거나 조정합니다.
3. Rule 6의 토큰 예산은 사용하는 모델과 작업 환경에 맞춰 바꿉니다.
4. 작은 작업 하나로 먼저 검증한 뒤 팀 규칙으로 넓힙니다.

## 이 템플릿이 막는 문제

- 요청 범위를 넘는 기능과 리팩터링
- 읽지 않은 코드의 성급한 수정
- 검증 없이 끝났다고 말하는 작업
- 상충하는 규칙을 조용히 섞는 판단
